# Agents merge on green CI, without human review

Stafeed is built by unattended agents: a scheduled Claude Code task on the owner's PC takes one `ready-for-agent` ticket every two hours, builds it test-first in its own worktree, reviews its own diff, and opens a PR that merges into `main` automatically once GitHub Actions is green. No human reviews or approves PRs. We chose this over human PR review because the owner wants to stay out of the build loop and spend their attention on product decisions, store releases and the `ready-for-human` tickets only they can do. CI on GitHub's Linux runners is the only gate (format, analyze, unit/widget tests, golden tests, web integration tests on every PR; Android emulator tests nightly), so the test suite is the definition of done: an agent may never weaken or delete a test to get green, and after two failed attempts it hands the ticket back as `ready-for-human`. Adding a human review step later is a small change; removing the gate is not allowed.
